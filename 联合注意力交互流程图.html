区别在组织，不在 attention 核心公式

普通自注意力

一张同宽 token 表
X: [B,L,D]
↓
同一层所有位置共用
WQ、WK、WV
↓
softmax(QKᵀ/√d + M)V
↓
通常共用这一层的
WO、FFN

这里的联合注意力

两张可以不同宽的 token 表
XV:[B,P,DV] · XA:[B,T,DA]
↓
一支一套投影，不是每行一套
QV/KV/VV · QA/KA/VA
↓
相容空间里沿 token 轴拼接
softmax(QKᵀ/√d + M)V
↓
按位置拆回两支
各自 WO、FFN / MoE
你的理解是对的：每个 token 用自己的 q 去匹配允许的 k，整行做 softmax，然后汇总对应 v。不同支先投影到兼容空间，就不再有“768怎么乘2560”的问题。
  • 一支的所有 token 共享这支的投影矩阵；同一层 WQ、WK、WV 是三组不同参数，不同层通常也各有参数。
  • softmax 对每个样本、每个查询头、每个查询位置独立，归一化轴是 key/token。视觉列和动作列一起进入同一个分母。
  • 动作读取视觉是分数矩阵的一个跨分支块，具有 cross-attention 的作用；这里的实际实现是联合拼接 Q/K/V，而不是先跑完 VLM，再接一个完全独立的 cross-attention。
  • 联合注意力是一个泛称；此图说明的是 LingBot 这份具体组织方式，不是所有多模态模型都这样实现。

怎样看这张图

第一次读

保持“五 token”模式，从第1步开始按“下一步”。图会聚焦对应部分，右边显示这一节点的输入、输出、公式和具体数值。

想知道箭头的意思

点节点后，右侧列出所有输入／输出关系，可继续点击上下游节点。图上蓝线是当前节点直接关联的数据路径，虚线是残差跳接。

跟踪一次视觉读取

选择 A₁ 的 Q，看分数／mask／softmax／加权 V。点击右侧矩阵 A₁→I 的格子，看自己的 q 怎么乘视觉 k；再点 I→A₁ 看反方向被禁止。

缩放与重排

滚轮以光标为中心缩放；左键拖空白平移，左键拖节点重排。中键拖动任意位置都能平移全图；也可开启上方“平移模式”，用左键拖节点或空白移动全图。重置可恢复初始布局。本页不保存旧坐标，因此下次打开不会被旧布局覆盖。

两套模式不要混淆：五token模式是1个样本、4/3维hidden、1头2维、2+3个token的手算例子。LingBot形状模式使用32/8查询与KV头、每头128维；B可调，P=80只是展示值，不是实际图像token计数。所有数值例子是人为设定，不是模型权重或训练打印。

本图范围

重点是一个 Transformer block 内部的组织。输入已经是带有位置信息的 hidden/token 表，不展开整个视觉编码、动作归一化和 τ 混合。详情会补充这些来源。真实网络还有 norm、Q/K norm、RoPE、时间 AdaNorm；教学例子明确省略／取恒等，不伪称复现真实数值。
